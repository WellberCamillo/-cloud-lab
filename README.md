# ☁️ Fundamentos Básicos da Cloud (AZ-900 - Microsoft Azure)

## 🔍 O que é Cloud Computing?
Cloud Computing é um modelo que permite o acesso remoto a recursos de computação (servidores, armazenamento, redes, bancos de dados, etc.) pela internet, de forma escalável, segura e com pagamento conforme o uso.

---

## 🧱 Infraestrutura da Nuvem

- **Data Centers**: Centros físicos com milhares de servidores conectados.
- **Virtualização**: Permite executar múltiplas máquinas virtuais (VMs) em um único servidor físico.
- **Rede Global**: Infraestrutura interconectada globalmente, garantindo alta performance e disponibilidade.

---

## ☁️ Modelos de Implantação

| Modelo      | Descrição                                                                 |
|-------------|---------------------------------------------------------------------------|
| Pública     | Recursos compartilhados hospedados por provedores como Azure, AWS, GCP.   |
| Privada     | Infraestrutura exclusiva de uma empresa, local ou em provedor externo.    |
| Híbrida     | Combinação da nuvem pública e privada, com integração entre ambas.         |

---

## 🛠️ Modelos de Serviço

| Modelo      | Descrição                                                                    | Exemplo (Azure)           |
|-------------|-------------------------------------------------------------------------------|----------------------------|
| IaaS        | Infraestrutura como Serviço: recursos básicos de computação.                 | Azure Virtual Machines     |
| PaaS        | Plataforma como Serviço: ambiente para desenvolver e hospedar aplicações.    | Azure App Services         |
| SaaS        | Software como Serviço: aplicativos disponíveis pela internet.                | Microsoft 365, Dynamics    |

---

## 🚀 Benefícios da Nuvem com Azure (AZ-900)

- ✅ **Escalabilidade**: Recursos sob demanda, com escalonamento automático.
- ✅ **Redução de Custos**: Pague apenas pelo que usar (*pay-as-you-go*).
- ✅ **Alta Disponibilidade**: Infraestrutura redundante com SLA garantido.
- ✅ **Segurança Avançada**: Criptografia, controle de acesso e compliance global.
- ✅ **Acessibilidade**: Acesso remoto e seguro de qualquer lugar.
- ✅ **Automação**: Suporte a DevOps e scripts para automação de tarefas.
- ✅ **Inovação Tecnológica**: Acesso a IA, Machine Learning, IoT e muito mais.
